Lung Cancer Prediction System

A machine learning web application that predicts the likelihood of lung cancer based on patient symptoms and risk-related factors. The project uses a Random Forest Classifier for prediction, FastAPI as the backend API, and React + Vite for the frontend.

🚀 Features
User-friendly React frontend
11 patient input features
Yes/No input selection
Automatic feature engineering for ANXYELFIN
Random Forest-based prediction
FastAPI REST API
React-to-FastAPI integration using HTTP requests
CORS enabled for frontend-backend communication
Pickle-based trained ML model
Responsive dark-themed UI
